## 🛠️ Tecnologías usadas

| Tecnología | Descripción |
|---|---|
| **HTML5** | Estructura semántica del documento |
| **CSS3** | Estilos embebidos en `<style>` dentro del mismo HTML |
| **Google Fonts** | Tipografía `Outfit` importada desde CDN |
| **Font Awesome 6** | Íconos vectoriales importados desde CDN |

---

## 🎨 Características del diseño

- Layout de **dos columnas** con CSS Grid (`grid-template-columns: 240px 1fr`)
- **Sidebar** con gradiente azul marino → violeta
- **Foto circular** con borde de color rojo-rosado
- **Animación de entrada** suave con `@keyframes`
- **Efectos hover** en tarjetas y enlaces
- **Responsive**: a menos de 640px cambia a una sola columna
